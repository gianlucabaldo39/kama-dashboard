# kama-dashboard
## tagging.html — Video Tagging partite
Apri `tagging.html` nel browser (Chrome/Edge consigliati), carica il video della partita e tagga gli eventi con i pulsanti personalizzabili o con le scorciatoie da tastiera. Filtra per tipo di evento, riproduci i clip in sequenza, scarica il montaggio in `.webm` oppure esporta CSV / script ffmpeg per tagliare il video originale senza perdita di qualità.
